# План «Щитовик»

Калькулятор электрощита для квартир, домов, гаражей и малых коммерческих объектов (РФ): линии,
автоматы/УЗО/дифавтоматы, кабель, баланс фаз, проверки (Iz, ΔU, петля КЗ), щит на DIN-рейках,
подбор моделей, смета-вилка, PDF. Android, iOS, Web. Бесплатно, офлайн, без регистрации.
Расчёт ориентировочный и не заменяет проект.

## Решения

| Тема | Решение |
|---|---|
| Нормы | ГОСТ Р 50571.5.52-2011, ПУЭ-7, ГОСТ IEC 60898-1, СП 256.1325800.2016. Каждое правило в `engine` ссылается на пункт нормы. |
| Режимы | Простой (шаблоны, значения по умолчанию) и экспертный (все параметры линии) на одном ядре. |
| Данные | Только на устройстве; обмен файлом `.shchitovik`. Хранится ввод, ручные правки и выбор моделей; результаты пересчитываются. |
| Числа | Физика – `double`, деньги – `int` копейки, мощность – `int` Вт. |
| Каталог | ~2000 моделей 10 производителей; обновление JSON с `shchitovik.ru/catalog`, без сети – встроенный. |
| UI | Широкий экран (≥ 840 dp) – боковая навигация, главный раздел – щит; телефон – мастер Объект → Помещения → Линии → Смета, на «Линиях» переключатель «Щит / Список» (выбор запоминается). |
| Щит | Ширина аппаратов – из моделей сметы; корпус – наименьший типовой с резервом ≥ 20 % (допущение, VERIFICATION E9); на телефоне прокрутка. Раскладка – в `estimate_core`; ручная перестановка (режим «Переставить»: стрелки, клавиатура, на широком экране перетаскивание) и выбор корпуса хранятся в `EstimateInput.board`; разрыв группы УЗО разрешён с предупреждением. Порядок монтажа: ввод → УЗИП → розетка на DIN (свой дифавтомат) → ПП УЗО → реле напряжения → неотключаемые линии → выключатель нагрузки → остальные (VERIFICATION E10). |
| Защита | Мокрые зоны (ванная, приборы с водой) – всегда отдельный дифавтомат, при любой стратегии УЗО (VERIFICATION E11). При однофазном вводе трёхфазные приборы не предлагаются. |
| Идентификатор | `ru.shchitovik.app`, домен `shchitovik.ru`. |
| Ошибки | Sentry в релизах выключен (политика: данные не собираются). |
| Инфраструктура | CI/CD: GitHub Actions (`.github/workflows`, Flutter по `.fvmrc`): проверки на runner'ах GitHub, релиз по тегу `vX.Y.Z` – подписанные AAB/APK и черновик GitHub Release; Web и каталог – Docker-образ за Caddy на своём VPS (или nginx/Caddy без Docker); iOS собирается на Mac владельца (вручную или как self-hosted runner `macos`). |
| Тесты | Табличные на фиксированных сетках, без property-based и `bloc_test`. |

Стек: Flutter 3.47.8 (FVM), flutter_bloc, go_router, drift, freezed, pdf/printing, gen-l10n (ru).
Структура и правила кода – [AGENTS.md](../AGENTS.md).

## Сделано

Нормативные данные, `electrical_core`, `estimate_core`, автоматическая верификация (оракул, 403 вектора),
хранилище drift и файл `.shchitovik`, PDF, каталог и деплой (nginx или Caddy), UI на дизайн-системе
«Чертёж» (`common_ui`), подготовка к выпуску (подпись Android, CI для сторов, политика, тексты сторов),
ручная перестановка на щите и щит в PDF; порядок монтажа с неотключаемой линией, выключателем
нагрузки и розеткой на DIN, дифавтоматы на мокрые зоны, подсказка о линиях без длины.
