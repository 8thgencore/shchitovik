# План «Щитовик»

Калькулятор электрощита для квартир, домов, гаражей и малых коммерческих объектов (РФ): линии,
автоматы/УЗО/дифавтоматы, кабель, баланс фаз, проверки (Iz, ΔU, петля КЗ), щит на DIN-рейках,
подбор моделей, смета-вилка, PDF. Android, iOS, Web. Бесплатно, офлайн, без регистрации.
Расчёт ориентировочный и не заменяет проект.

## Решения

| Тема | Решение |
|---|---|
| Нормы | ГОСТ Р 50571.5.52-2011, ПУЭ-7, ГОСТ IEC 60898-1, СП 256.1325800.2016. Каждое правило в `engine` ссылается на пункт нормы. |
| Режимы | Простой (шаблоны, значения по умолчанию) и экспертный (все параметры линии) на одном ядре. |
| Данные | Только на устройстве; обмен файлом `.shchitovik`. Хранится ввод, ручные правки и выбор моделей; результаты пересчитываются. |
| Числа | Физика — `double`, деньги — `int` копейки, мощность — `int` Вт. |
| Каталог | ~2000 моделей 10 производителей; обновление JSON с `shchitovik.ru/catalog`, без сети — встроенный. |
| UI | Широкий экран (≥ 840 dp) — боковая навигация, главный раздел — щит; телефон — мастер Объект → Помещения → Линии → Смета, на «Линиях» переключатель «Щит / Список» (выбор запоминается). Выбрано UI-прототипом из пяти вариантов. |
| Щит | Ширина аппаратов — из моделей сметы; корпус — наименьший типовой с резервом ≥ 20 % (допущение, VERIFICATION E9); на телефоне прокрутка. |
| Идентификатор | `ru.shchitovik.app`, домен `shchitovik.ru`. |
| Ошибки | Sentry в релизах выключен (политика: данные не собираются). |
| Инфраструктура | CI: gitlab.com + свой runner (`.gitlab-ci.yml`) или GitHub Actions (`.github/workflows`), один образ Flutter; Web и каталог — nginx на своём VPS; iOS собирается на Mac владельца. |
| Тесты | Табличные на фиксированных сетках, без property-based и `bloc_test`. |

Стек: Flutter 3.47.6 (FVM), flutter_bloc, go_router, drift, freezed, pdf/printing, gen-l10n (ru).
Структура и правила кода — [AGENTS.md](../AGENTS.md).

## Сделано

| Этап | Что |
|---|---|
| 0. Каркас | монорепо по sizzle_starter, CI |
| 1. Нормативные данные | таблицы норм с источниками, справочник приборов, шаблоны комнат |
| 2. `electrical_core` | токи, группировка, защита, кабель, петля КЗ, фазы, ввод, ручные правки |
| 3. `estimate_core` | совместимость, автоподбор моделей, сценарии, смета-вилка |
| 4. Верификация (авто) | Python-оракул, 403 вектора, инварианты, проверка каталога |
| 5. Хранилище | drift (+ Web wasm), файл `.shchitovik` с миграциями |
| 7. PDF | отчёт с линиями, фазами, спецификацией, сметой, допущениями |
| 8. Каталог и деплой | загрузка каталога, nginx, задачи деплоя |
| 6. UI | экраны; адаптивный каркас и щит на рейках |
| 9. Подготовка к выпуску | подпись Android, CI для сторов, политика, тексты сторов, id и домен |

## Осталось

1. **Ручная верификация** — условие публикации: открытые пункты
   [VERIFICATION.md](../verification/VERIFICATION.md) (официальные тексты норм, эксперт, розничные цены,
   резерв корпуса E9).
2. **Выпуск** — шаги владельца в [RELEASE.md](RELEASE.md): домен и сервер, ключ Android, аккаунты
   сторов, иконка и скриншоты, заполнить политику, версия 1.0.0.
3. **Проверка на устройствах:** «квартира за 5 минут» и три демо-проекта на Android, iOS, Web;
   обмен `.shchitovik` между платформами; PDF.
4. **Вторая очередь:** ручная перестановка на щите и щит в PDF, ручной перенос групп и приборов,
   однолинейная схема, дизайн, лендинг, синхронизация, PRO.
