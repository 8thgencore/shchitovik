# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Stripe
- **Notes:** Flutter app (Android, iOS, Web) with its own design system «Чертёж» in `common/common_ui`: ink on paper, signal orange for the current element, IBM Plex Sans for text and IBM Plex Mono for values, 1px hairlines, 3–4px corners. Screens are built from `Ui*` widgets and `UiColors`/`UiTextStyles` roles, never raw colours or bare Material widgets; Material stays underneath only for text input, menus, dialogs and routing. Tokens, rules and rejected options: `design-system/shchitovik/MASTER.md`. Web skills' CSS guidance maps to these tokens and widgets.

## Banned anti-aesthetics

- Gratuitous glassmorphism / backdrop blur (`BackdropFilter`) without a high-contrast boundary
- Floating pastel pill badges for ordinary metadata
- Arbitrary decorative gradients and neon glowing borders
- Multi-color radial rainbow gradients on standard CTAs
- Cartoon empty-state illustrations (people waving / high-fiving)
- Nested scrollbars and icon bloat inside inputs

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** ≥ 4.5:1 for normal text; ≥ 3:1 for large text, borders and UI components — in both light and dark themes
- **Touch / focus:** Targets ≥ 44×44 (Material default 48dp — keep it); refined visible focus ring for keyboard on Web; every icon-only control has `tooltip`/semantics label

## Brand tone and microcopy voice

- **Voice:** Utilitarian & Minimal
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** UI copy is Russian (via `common_translations`). Precise engineering vocabulary, units always shown (А, мм², кВт, ₽). Verb-first buttons; no «ОК»/«Отправить»/«Продолжить» as generic labels. Errors never blame the user and always offer recovery.

## Icon library

- **Library:** Lucide (`lucide_icons_flutter`), weight `300` (1.55 stroke, matches the hairlines)
- **Package / path:** `UiIcons.*` from `package:common_ui/common_ui.dart` — screens never reference `LucideIcons` or `Icons` directly
- **Notes:** Add a new icon as a named entry in `UiIcons`. No Material or Cupertino icons, no emoji as UI icons.

## Accepted exceptions

- **Switchboard drawing (`SwitchboardView`):** DIN modules keep real proportions (36px per module, 34px tap width; module texts use 11–12px mono), below the 44×44 target, and their inner geometry is exempt from the 4/8pt grid. Every circuit is also reachable through a full-size row in the circuits list, and each module has a tooltip with the full description.

## Agent rules

1. Read this profile before creating or editing any UI, theme, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library. Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
