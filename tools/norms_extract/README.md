# norms_extract

Скрипты, которыми получены наборы данных `engine/norms_data/data/*.json` из текстов норм.
Тексты норм хранятся локально в `reference/norms_src/` и в репозиторий не попадают.
Запуск — см. [engine/norms_data/README.md](../../engine/norms_data/README.md).

Скрипты используют только стандартную библиотеку Python; запускайте с `python3 -I`.
