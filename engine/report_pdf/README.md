# report_pdf

PDF-отчёт проекта на чистом Dart (`package:pdf`), формат A4 альбомный:

1. Титул, итоговый статус и оговорка «ориентировочный расчёт».
2. Исходные данные: помещения и приёмники.
3. Ввод: нагрузка по приборам и по СП 256, вводной автомат, противопожарное УЗО, кабель ввода.
4. Групповые линии: защита, кабель, Iz, ΔU, Iк, статус.
5. Замечания по проверкам и причины установки УЗО (со ссылками на нормы).
6. Баланс фаз (трёхфазный ввод).
7. Спецификация и смета-вилка, предупреждения, «не включено».
8. Допущения расчёта и нормативная база.

Шрифт передаётся байтами (`ReportFonts`); приложение берёт Noto Sans (SIL OFL 1.1) из
`app/assets/fonts`. Тесты пишут примеры в `build/report_*.pdf` для просмотра.
