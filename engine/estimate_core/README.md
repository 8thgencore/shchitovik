# estimate_core

Подбор аппаратов и смета «Щитовика» на чистом Dart.

```dart
final result = calculateProject(input);                    // electrical_core
final estimate = calculateEstimate(input, result, const EstimateInput()); // смета-вилка
```

- **Слоты** (`slotsFor`): что нужно поставить — вводной автомат, противопожарное и групповые УЗО,
  автомат/УЗО/дифавтомат каждой линии. Id слотов стабильны (`<id линии>/rcbo`), поэтому выбор
  пользователя переживает пересчёт.
- **Совместимость** (`checkCompatibility`): функция, полюса, номинал (для УЗО — не ниже), кривая,
  отключающая способность, ток утечки, тип УЗО (AC < A < F < B), селективность; статус
  `exact` / `compatibleWithDifferences` / `incompatible`.
- **Автоподбор**: серия сегмента сценария (эконом/стандарт/премиум), покрывающая больше слотов,
  затем самая дешёвая совместимая модель сегмента, любого сегмента, усреднённая цена.
- **Выбор пользователя** хранится снимком модели (`ApparatusSelection`); если модель перестала
  подходить, слот подбирается заново и появляется предупреждение `stale_selection`.
- **Кабель**: цена за метр × длина × запас 10 %; линии без длины не суммируются.
- **Итог** — вилка min/typical/max в копейках, список «не включено».

Каталоги — `data/*.json`, генераторы и валидатор — `tools/catalog/`. Встроенная копия
пересобирается `dart run tool/embed_data.dart`.
